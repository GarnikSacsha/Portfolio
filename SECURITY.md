# Security Policy

## Scope & Architecture
This repository contains a purely static portfolio website built with semantic HTML, CSS, and vanilla JavaScript. It has no server-side execution, no backend database, no user authentication, and no form processing.

## Reporting a Vulnerability
If you identify a security vulnerability, sensitive data exposure, or privacy concern:

1. **Do not disclose the issue publicly** in an open GitHub issue, pull request, or discussion.
2. Use **GitHub Private Vulnerability Reporting** via the "Security" tab of this repository if enabled.
3. Alternatively, contact Denys directly via Telegram: [`https://t.me/PackChoOi`](https://t.me/PackChoOi).

Please include:
- A clear description of the issue.
- Steps to reproduce or the affected file/commit.
- Potential impact.

## Repository Security Guidelines
- **Zero Secrets:** No API keys, credentials, tokens, private keys, database URLs, or passwords belong in this codebase.
- **Data Privacy:** Product screenshots and reference previews must be scrubbed of customer identifiable information (PII), sensitive client data, or internal credentials prior to commit.
- **Deployment Status:** Deployment is currently on hold pending final review.
